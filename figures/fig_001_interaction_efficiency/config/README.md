# Configuration

- `aggregation.json`: model set, name aliases, expected rows, mean definition, and precision.
- `data_schema.json`: every CSV field, unit, missing convention, and requirement.
- `plot_handoff.json`: four panel inputs, display divisors, palette, and scope constraints; layout is for the collaborator to implement.

None of these files supplies missing task IDs, run IDs, seeds, or confidence intervals.
